## Project Description
A JavaScript application developed using ES6 standards and the Promise concept to simulate an asynchronous operation and display the result after successful completion.

## Aim
To develop a JavaScript application using ES6 features and Promise concepts to handle asynchronous operations.

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)

## ES6 Concepts Used
- let
- const
- Arrow Functions
- Template Literals
- Promise
- .then()
- .catch()
- .finally()

## Features
- Start asynchronous operation using a button.
- Display an operation-in-progress message.
- Simulate a delay of 2 seconds using setTimeout().
- Display successful completion message.
- Handle errors using Promise rejection.
- Enable the button after operation completion.

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open index.html in a web browser.
4. Click the Start Operation button.
5. Observe the loading message.
6. After 2 seconds, the success message will appear.
